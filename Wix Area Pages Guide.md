# Area pages: duplicate-and-paste pack (Harmony)

The Harmony editor has no dynamic pages, so build the area pages as regular pages.

## Build the template once (Sandton)
1. **Pages & Menu → + Add Page → Blank**, or ask Harmony: *"Create a new page called 'Artificial Grass Sandton' using the same layout and styles as the Gauteng Service Area page, with these sections in order: Hero (eyebrow, H1, intro, Request Free Assessment + WhatsApp buttons) · Intro (H2 + paragraph) · Pricing strip · Areas we cover · FAQ (3 questions) · Quote CTA. Use placeholders for images. Don't generate images."*
2. Paste the Sandton text below into it.
3. Paste this pricing strip; it's the same on every page:
   > Standard R350–R450 · Premium R500–R650 · Luxury R700–R850 per m², fully installed. Indicative only — your price is fixed in writing after a free site measure.

## Then, for each other area
1. **Pages & Menu** → hover over the Sandton page → **⋯ → Duplicate**.
2. Rename the page to the area name. **Hide it from the menu** (⋯ → Hide from menu); it's linked from Service Areas instead.
3. ⋯ → **SEO basics** → set the URL slug, title tag and meta description from below.
4. Click each text block and replace it with the area's text.
5. In **Service Areas**, link the area name to the new page.

Total: roughly 5 minutes per page.
